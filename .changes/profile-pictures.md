Everyone can have a profile picture, shown beside their name around the house. Without one, their initials sit in a soft circle instead.

- In Settings → Profile, choose a photo, slide it into the circle and save. You can change or remove it there at any time. An admin can remove anyone's picture from their page in Admin → Users, but only you can put one up.
- Settings → Profile also takes your birthday: the whole date, day, month and year. Once it's set you can change it but not clear it. An admin can set anyone's birthday from their page in Admin → Users.
- Settings → Notifications has a Morning memories switch, on for everyone to start with: a push each morning with what happened on this day in past years, and whose birthday it is.
- `GHAR_TIMEZONE` sets where the household lives, so "today" and dates follow your clock rather than the server's. Dates read the way that country writes them unless `GHAR_LOCALE` says otherwise. See DEPLOY.md.
