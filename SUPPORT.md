# Getting help

- **Setting Ghar up or running it:** read [`DEPLOY.md`](./DEPLOY.md) first. If you're still stuck,
  ask in [Discussions, under Q&A](https://github.com/Things-Varun-Codes/ghar/discussions/categories/q-a).
- **Something is broken:** [open a bug report](https://github.com/Things-Varun-Codes/ghar/issues/new?template=bug_report.yml).
  Say which version you run and how.
- **An idea or a mini app you'd like:** check [`ROADMAP.md`](./ROADMAP.md), then start a thread in
  [Discussions, under Ideas](https://github.com/Things-Varun-Codes/ghar/discussions/categories/ideas).
- **A security problem:** not in public, please. [`SECURITY.md`](./SECURITY.md) says how.

This is a spare-time project with one maintainer, so answers can take a few days.
