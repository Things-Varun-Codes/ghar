# Code of conduct

Ghar is a small project about homes and families, and the people who work on it should be able to
do so without being made to feel unwelcome. This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The short version:

- Be kind and patient, especially with people who are new to the code or to open source.
- Disagree about the work, not about the person. Criticism of code is fine; insults,
  harassment and personal attacks are not.
- No sexualised language or imagery, no unwelcome attention, and no publishing of anyone's
  private information.
- Remember that maintainers are volunteers doing this in their spare time.

This applies in issues, pull requests, discussions and anywhere else someone is representing the
project.

## Reporting

If someone's behaviour is a problem, report it privately to the maintainer,
[@varun-biju](https://github.com/varun-biju), through
[the private report form](https://github.com/Things-Varun-Codes/ghar/security/advisories/new)
and say that it's a conduct report. Only the maintainers can read what you send there. You can also
use GitHub's own "Report content" link on any comment.

Reports are read, kept private and acted on. Depending on what happened, that can mean a quiet
word, an edited or removed comment, or a temporary or permanent ban from the project.
